# 3.2 プロンプトファイル

プロンプトページは、選択したアプリのグローバルプロンプトファイルを読み取り専用で表示します。

## ファイルの表示

1. サイドバーの **プロンプト** を開きます。
2. ドロップダウンでアプリを選択します。
3. 実際のファイルパスと元の Markdown 本文を確認します。

代表的な既定のパスを以下に示します。設定で構成ディレクトリを変更した場合は、ページに表示されたパスを確認してください。

| アプリ | 既定のファイルパス |
| --- | --- |
| Claude Code | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |
| Pi | `~/.pi/agent/AGENTS.md` |

## 操作

- **更新** で外部編集後のファイルを再読み込みします。ウィンドウにフォーカスが戻ったときも再読み込みします。
- **本文をコピー** は元のテキストと改行を保持します。
- ヘッダーの **⋯** メニューからパスのコピーと構成フォルダーを開く操作ができます。

ファイルが存在しない場合、空の場合、読み込みエラーの場合を区別して表示します。このページではライブラリ、プリセット、システムプロンプト、テンプレートを管理しません。編集には外部エディターを使用してください。
