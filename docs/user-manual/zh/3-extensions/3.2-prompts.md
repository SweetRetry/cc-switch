# 3.2 提示词文件

提示词页只读查看所选应用的全局提示词文件。

## 查看文件

1. 点击左侧栏的 **提示词**。
2. 在应用下拉框中选择应用。
3. 查看页面显示的实际路径和原始 Markdown 正文。

常见默认路径如下。设置中的自定义配置目录会影响实际路径，以页面显示为准。

| 应用 | 默认文件路径 |
| --- | --- |
| Claude Code | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |
| Pi | `~/.pi/agent/AGENTS.md` |

## 页面操作

- **刷新** 重新读取文件。在外部编辑器修改后可以立即刷新，窗口重新获得焦点时也会重新读取。
- **复制正文** 保留文件中的原始文本和换行。
- 页头 **⋯** 菜单提供复制文件路径和打开配置目录。

文件不存在、文件为空和读取失败会显示不同状态。此页不提供提示库、新增、编辑、启用、导入、系统提示或模板管理。修改文件请使用外部编辑器。
