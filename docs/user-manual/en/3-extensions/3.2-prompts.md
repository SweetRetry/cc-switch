# 3.2 Prompt Files

The Prompts page displays the selected app's global prompt file as read-only text.

## View a File

1. Open **Prompts** in the sidebar.
2. Select an app from the dropdown.
3. Read the actual file path and original Markdown content.

Common default paths are listed below. Custom configuration directories change the actual path; use the path shown on the page.

| App | Default file path |
| --- | --- |
| Claude Code | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |
| Pi | `~/.pi/agent/AGENTS.md` |

## Actions

- **Refresh** reads the file again after an external edit. The file also refreshes when the window regains focus.
- **Copy content** preserves the original text and line breaks.
- The header **⋯** menu offers copying the file path and opening the configuration folder.

Missing files, empty files and read errors have separate states. The page does not manage libraries, presets, system prompt files or templates. Edit the file in an external editor.
